Mochi's Lantern Garden — a cute 2D canvas tower defense. A chubby orange cat, Mochi, defends a paper-lantern garden at dusk from shadow bugs. Place cat towers on the garden plots, earn coins for every bug swatted, and survive all 10 waves — including the Shadow Moth boss. Towers standing in a lantern's glow fight 25% better, and the garden's light dims as the lantern loses lives.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Click to start, click a shop card and a plot to build, click Start Wave, and click a tower to upgrade or sell it. Space starts and restarts, P pauses, F toggles 2x speed, M mutes.
